# Design Product Alignment Review

Gap analysis behind the design product-alignment documentation pass
(2026-07-26). Read alongside `docs/design/DESIGN_HANDOFF.md` (frame
mapping) and `docs/PROGRESS.md` (what has actually shipped, through
Milestone 6). This document records *why* each documentation change was
made; it does not restate normative rules that already live in
`docs/product/PRD.md`, `docs/product/ROADMAP.md`,
`docs/design/DESIGN_SYSTEM.md`, `docs/design/ACCESSIBILITY.md`,
`docs/engineering/ARCHITECTURE.md`, or `docs/engineering/CONTENT_MODEL.md`.

**Design-tool access note:** the design tool's MCP connection was
rate-limited for this entire pass (Starter plan) — every row below compares
the *written* confirmed decisions in the alignment request against the
current repository, not against an actually-opened design-tool frame.
Visual/spacing specifics remain pending re-verification
(`DESIGN_HANDOFF.md`).

## Explicitly not changed

* Content safety, source/approval/endorsement separation (PRD §3.1/§6.5), risk-based publication
  model (Milestone 6) — untouched; no design-tool decision overrides these, and the request's own
  source-of-truth priority places them above any design-tool frame.
* Offline-first, guest-first, no-forced-account principles — already satisfied by ADRs 0007/0009;
  only cross-references added.
* Room schema — no migration in this pass (documentation only); every new table mentioned above is
  forward-documented, not created.
